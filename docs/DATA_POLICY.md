# Data Policy

This source release does not include raw rosbags, maps, site photographs, or robot-specific Gazebo assets. The recordings are large and include information from a controlled underground utility-tunnel environment. The included source code has no hidden reference to a local bag path or an absolute machine path.

The paper's supplementary material contains the reported tabulated results, manual-label audit records, and result-generation notes. Raw data may be available from the corresponding author on reasonable request, subject to the applicable site and data-management approvals.

Users should not infer that a configuration calibrated for the reported LiDAR placement and reflector layout will transfer unchanged to a different robot or facility.
